# The PIV loop 

Read `docs/piv-loop.md` to understand what a PIV loop is.

Read `docs/git-conventions.md` before naming a branch, writing a commit message. It holds the rules for how to write them.

Read `docs/skill-writing.md` before writing or editing a skill, a template or a tracker doc. It holds the rules for how to write them.

Good Skills are concise, well-structured, and tested with real usage. This guide provides practical authoring decisions to help you write Skills that Claude can discover and use effectively. Follow the bellow guide on how to create them:

- [Core principles](docs/best-practices/core-principles.md): Fundamental principles for creating concise, well-structured, and effective Skills, including degrees of freedom and model compatibility.
- [Skill structure](docs/best-practices/skill-structure.md): Guidelines for organizing files, defining metadata, writing effective descriptions, and using direct references for progressive disclosure.
- [Workflows and feedback loops](docs/best-practices/workflows-and-feedback-loops.md): Practices for structuring complex workflows with sequential steps, checklists, iterative validation, and feedback loops.
- [Content guidelines](docs/best-practices/content-guidelines.md): Guidelines for avoiding outdated time-sensitive information and maintaining consistent terminology across Skills.
- [Common patterns](docs/best-practices/common-patterns.md): Patterns for defining output templates, providing concrete input/output examples, and creating conditional workflows.
- [Evaluation and iteration](docs/best-practices/evaluation-and-iteration.md): Methods for evaluating Skills, establishing baselines, testing real-world scenarios, and improving instructions based on results and feedback.
- [Anti-patterns to avoid](docs/best-practices/anti-patterns-to-avoid.md): Practices to avoid, including Windows-style paths and excessive options that make decisions harder.
- [Advanced: Skills with executable code](docs/best-practices/advanced-executable-code.md): Recommendations for executable scripts, error handling, dependencies, visual analysis, and validation of complex operations.
- [Technical notes](docs/best-practices/technical-notes.md): Technical details about YAML frontmatter requirements, token budgets, runtime environments, MCP references, and file access.
- [Checklist for effective Skills](docs/best-practices/checklist-for-effective-skills.md): A checklist for reviewing quality, structure, code, validation, and testing before distributing a Skill.
