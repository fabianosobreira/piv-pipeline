# Skill-writing best practices

Good Skills are concise, well-structured, and tested with real usage. These guides give practical authoring decisions to help you write Skills that Claude can discover and use effectively. Follow the guides below.

- [Core principles](core-principles.md): Fundamental principles for creating concise, well-structured, and effective Skills, including degrees of freedom and model compatibility.
- [Skill structure](skill-structure.md): Guidelines for organizing files, defining metadata, writing effective descriptions, and using direct references for progressive disclosure.
- [Workflows and feedback loops](workflows-and-feedback-loops.md): Practices for structuring complex workflows with sequential steps, checklists, iterative validation, and feedback loops.
- [Content guidelines](content-guidelines.md): Guidelines for avoiding outdated time-sensitive information and maintaining consistent terminology across Skills.
- [Common patterns](common-patterns.md): Patterns for defining output templates, providing concrete input/output examples, and creating conditional workflows.
- [Evaluation and iteration](evaluation-and-iteration.md): Methods for evaluating Skills, establishing baselines, testing real-world scenarios, and improving instructions based on results and feedback.
- [Anti-patterns to avoid](anti-patterns-to-avoid.md): Practices to avoid, including Windows-style paths and excessive options that make decisions harder.
- [Advanced: Skills with executable code](advanced-executable-code.md): Recommendations for executable scripts, error handling, dependencies, visual analysis, and validation of complex operations.
- [Technical notes](technical-notes.md): Technical details about YAML frontmatter requirements, token budgets, runtime environments, MCP references, and file access.
- [Checklist for effective Skills](checklist-for-effective-skills.md): Final check for quality, code, and testing before distributing a Skill.
